# FunBall

球球遊樂場：支援滑鼠與觸控的網頁撞球遊戲，使用 HTML Canvas 製作，無需安裝套件。

遊戲網址：https://arvinyang1995.github.io/FunBall/

## 玩法

- 點住球往後拖曳，放開擊球；拖得越遠，力道越大。
- 瞄準時暫停場地，按 Esc 取消，也能切換成滑鼠推球模式。
- 將球推進相同圖形的球洞，每顆加 100 分。
- 三顆以上同圖形球相連會爆破，3 秒內再次爆破可疊加連鎖。
- 球與球洞使用高對比圖形標記，不需只靠顏色辨識。

## 本機執行

直接用瀏覽器開啟 `index.html`。

## 部署

GitHub Pages 從 `main` 分支根目錄發布，推送更新後會自動重新部署。
